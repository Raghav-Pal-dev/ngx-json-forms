100%TypeScript

JSON-Driven

Every field, label, validator, layout, and event lives in a plain array — no markup needed.

Signal-First

Built on Angular 19 signals and computed values. Zone-less ready, auto change detection.

External Control

Inject FormEngineService anywhere — patch, swap options, add/remove fields at runtime.

Conditional Fields

Use showWhen to reactively show/hide fields based on other field values.

Multi-Adapter

Core has zero UI deps. Swap PrimeNG for Angular Material by switching one adapter package.

Built-in Validation

required, min/maxLength, pattern, email — all in JSON with fully customisable messages.
